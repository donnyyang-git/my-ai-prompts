# 我的 AI Prompts

這個倉庫整理各種 AI Prompt，方便快速複用與分類管理。

## 目錄結構

- `01-工作效率/`：適合工作、溝通、翻譯與會議整理
- `02-程式開發/`：適合程式碼審查、系統設計與開發流程
- `03-開源吸納/`：收集與引用開源／社群優質 Prompt
- `templates/`：新 Prompt 的範本
- `.github/workflows/`：自動更新 README 的 GitHub Actions

## 使用方式

1. 依照任務類型選擇對應目錄
2. 複製既有 Prompt 內容
3. 修改成符合你的場景
4. 如有需要，再新增新的 Prompt 檔案

## 維護建議

- 依主題分類整理內容
- 每個 Prompt 保留標題、用途與範例
- 定期更新與優化內容
- 可搭配 GitHub Actions 自動生成索引
